# Sky Theme

If you are going to use this theme, please change path for application widget and weather location/api and install cava. Theme support Komorebi.

## Widgets

- Komorebi Workspaces
- Disk
- Applications
- WHKD
- Media
- Cava
- Clock
- Active Window
- Taskbar
- CPU
- Memory
- Weather
- Volume
- Language
- WiFi
