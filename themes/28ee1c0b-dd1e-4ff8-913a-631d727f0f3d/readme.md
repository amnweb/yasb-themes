# Comfyppuccin

This theme has the Mocha flavor with the mauve accent, you may customize this theme to your liking. This theme requires the SF Pro Rounded and JetBrains Mono NFP fonts to be installed on your system.

## Widgets

- Home
- Wallpapers
- Media
- Notifications
- GlazeWM Workspaces
- Active Window
- Weather
- Volume
- Clock
- Battery
- Power Menu
