# GINpuccin

GINpuccin is a Catppuccin Mocha theme for YASB Reborn. It uses a solid Mocha Base bar with Mauve and Lavender accents, separated date and time widgets, colored system icons, spaced taskbar entries, and refined media controls.

## Widgets

- Power Menu
- Applications
- Systray
- Media
- Taskbar
- Clock
- WiFi
- Bluetooth
- Volume
- Brightness
- Language

## Requirements

- [JetBrainsMono Nerd Font](https://www.nerdfonts.com/font-downloads)
- [Komorebi](https://github.com/LGUG2Z/komorebi)
