# Fluent Sonoma

Featuring custom pill indicators, high-contrast dark popup panels, fully transparent overlays, and full interactive control widgets.

## Widgets

- Home
- Custom
- Applications
- CPU
- Memory
- Pomodoro
- Todo
- Bluetooth
- WiFi
- Battery
- Volume
- Notifications
- Control Center
- Clock
