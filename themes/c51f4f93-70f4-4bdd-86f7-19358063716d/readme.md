# Rangalipi

Rangalipi is a calm, high-contrast theme built around one accent colour. The bar is a translucent ink-blue glass rail split into rounded islands, so widgets read as separate chips without heavy borders. Text is a warm off-white and every active state - the focused workspace, the play button, the home glyph - uses a single amber accent.

The palette is defined once in `:root`, so recolouring the whole theme is a matter of editing a handful of variables. Popups share one frosted acrylic surface with a double hairline border, and status colours (green/amber/red) are reserved strictly for CPU, memory, disk and battery thresholds so they stay meaningful.

It is a full setup rather than a bare bar: workspaces, active layout and window stack for Komorebi, a mirrored cava visualiser, media controls with a scrolling title, a pomodoro timer, and a control centre. Collapsible groups keep the right side compact until you expand it.
