# HexDock

### Features:

- **6 Docks**:  
  - Workspace  
  - Window Titles  
  - Clock  
  - Media Controls  
  - Systray  
  - Custom Dock for Notifications, Wi-Fi, Volume, Disk, Wallpaper Change

- GlazeWM Workspaces

- Disk
- Wallpapers
- WiFi
