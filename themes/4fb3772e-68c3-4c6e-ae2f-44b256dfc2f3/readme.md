# Pywal Theme

A dynamic theme configuration for **YASB (Yet Another Status Bar)** that automatically syncs your bar’s color scheme with your current wallpaper using **Pywal**.

This setup uses a custom **PowerShell wallpaper watcher** to generate a **high-contrast, minimal 3-color palette** based on your wallpaper—keeping everything readable and aesthetic.

### 🔗 Original Repository & Full Installation

For the **Pywal sync script**, detailed setup instructions, and future updates, visit the original repository:

👉 **[My-Yasb-Config](https://github.com/AMVZEN/My-Yasb-Config)**

### ✨ Features

* 🎯 Automatically updates YASB colors when your wallpaper changes
* 🖼️ Extracts colors directly from the current wallpaper
* 🌑 Forces a clean, high-contrast dark theme
* 🔁 Auto-reloads YASB after applying new colors
