# Soft Segment

Theme where each widget is segmented with a 1px margin. If you want to use this theme, please enter your Weather API key and set the weather location.

## Screenshots

![Soft Segment preview 1](https://raw.githubusercontent.com/amnweb/yasb-themes/main/themes/f60c809d-1378-4042-9f11-46d0e9c37cf5/assets/preview-1.jpg)

## Widgets

- Home
- Komorebi Workspaces
- Clock
- Applications
- Disk
- CPU
- Memory
- Traffic
- WiFi
- Weather
- Volume
- Notifications
- Power Menu
