# Fluency

A status bar that has it all: the base goodies.

>[!NOTE]
For wallpapers, you have to change the directory provided in `config.yaml`

## Widgets

- Home
- Komorebi Control
- Komorebi Workspaces
- Notes
- Media
- Clock
- Systray
- Disk
- Memory
- CPU
- Battery
- WiFi
- Volume
- Weather
- Wallpapers
- Notifications
- Power Menu
