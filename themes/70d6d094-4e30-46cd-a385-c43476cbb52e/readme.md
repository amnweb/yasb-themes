# Blime

An eccentric theme for YASB / Komorebi by kbuckleys

UPDATE: The theme now uses the JetBrains font family, which you can obtain [here](https://www.jetbrains.com/lp/mono/).

## Widgets

- Komorebi Layout
- Komorebi Workspaces
- Traffic
- CPU
- Active Window
- Media
- Systray
- Clock
- Volume
- Notifications
